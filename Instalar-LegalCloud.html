A. Forma más fácil (carpeta lista, sin XAMPP)

Si le pasaron LegalCloud-listo, no instale XAMPP. Copie la carpeta, doble clic en INICIAR.bat, entre con admin@legalcloud.com / password. No cierre la ventana negra.

B. Descargar e instalar XAMPP (necesario para PHP y MySQL)

XAMPP instala PHP y MySQL. Elija un XAMPP con PHP 8.3 o 8.5. El de PHP 8.2 no sirve para LegalCloud.

Descarga oficial: https://www.apachefriends.org/download.html

B5. Comprobar el PHP de XAMPP

Si sale PHP 8.2 o menos, LegalCloud no instala. Instale PHP 8.5 (paso D2) o use la carpeta LegalCloud-listo.

B6. Crear la base legalcloud

phpMyAdmin es XAMPP (puerto 80). LegalCloud se abre en http://127.0.0.1:8000/app, no en localhost sin :8000.

J. Si algo falla

  • “No se reconoce”: use cmd, no PowerShell. O ejecute el set PATH de XAMPP (B4).
  • Error de base / SQLSTATE: XAMPP → Start en MySQL. Base llamada legalcloud.
  • php no se reconoce: use C:\xampp\php\php.exe o el set PATH.
  • Composer pide PHP 8.3: el PHP 8.2 de XAMPP viejo no sirve. Instale PHP 8.5 (D2) o LegalCloud-listo.
  • Composer no está en winget: use D3 y D4. En el instalador elija C:\xampp\php\php.exe.
  • “composer no se reconoce” o falta vendor/autoload.php: en C:\repo\LegalCloud use E9a y E9b (php composer.phar install). Luego otra vez key:generate, migrate y seed.
  • Página en blanco: npm run build.
  • ERR_CONNECTION_REFUSED: no está corriendo artisan serve.
  • localhost sin :8000 es XAMPP, no LegalCloud.
